# Bayram (Patr10on)

Android Developer & Mobile Systems Engineer. Focused on custom Android launchers, AOSP internals, and mobile application security.

---

### 📌 Featured Projects

- 🚀 **[Xenci Launcher](https://github.com/Patr10on/Xenci-Launcher)**  
  Customizable open-source Android launcher based on Neo Launcher & Launcher3. Features a Xiaomi-style hidden apps vault with pinch-out gesture, biometric & PIN security, iOS navigation pill, and a pure zero-native StackBlur engine fully aligned for 16 KB page-size (Android 11–17).

- 🛡️ **[x3nc1-DroidAnalyzer](https://github.com/Patr10on/x3nc1-DroidAnalyzer)**  
  Static security analysis and auditing tool for Android APK binaries. Inspects manifest configurations, exported components, and permission risks.

- 🏝️ **[Dynamic-Island-Android](https://github.com/Patr10on/Dynamic-Island-Android)**  
  Interactive floating island and notification pill experience for Android devices.

- ⚡ **[dpi-android](https://github.com/Patr10on/dpi-android)**  
  Display density (DPI) and screen resolution tuning utility for Android.

- 🧰 **[Cybertool-security-toolkit](https://github.com/Patr10on/Cybertool-security-toolkit)**  
  Multi-purpose security, reconnaissance, and penetration testing toolkit.
